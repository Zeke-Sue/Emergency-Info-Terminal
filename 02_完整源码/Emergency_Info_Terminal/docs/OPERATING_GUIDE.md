# 操作说明

拨码按SW1、SW2、SW3、SW4排列，1为高电平，0为低电平。

| 模式 | A板拨码 | 操作 |
|---|---|---|
| 图片与定时轮播 | 0000 | KEY1上一张、KEY2下一张、短KEY3暂停/恢复、长KEY3轮换2/5/10秒 |
| 日常语音及滚动字幕 | 0001 | KEY1/KEY2切图，短KEY3暂停/恢复 |
| 画质及转场菜单 | 0010 | KEY3下一项、KEY4上一项、KEY1减少、KEY2增加 |
| 原生测试音 | 1100 | KEY1/KEY2切换测试页面及对应频率 |
| 录音与音频可视化 | 1101 | KEY1/KEY2切页，短KEY3暂停/恢复 |

画质菜单前五项为BRI亮度、CON对比度、SAT饱和度、G Gamma、T色温。

B板0100用于地震演练，0101用于火警演练。KEY3选择SEND或CLEAR；KEY4短按松开后再次按住约3秒再松开完成二次确认。确认逻辑阈值为2秒，约3秒的操作留有余量。
火警发布后KEY1/KEY2选择危险区域，再用KEY4二次确认应用。同一事件更新位置，绿色路线随封锁集合重算。
长KEY2切换BLOCK/OPEN，KEY1/KEY2选区，KEY4二次确认；手动封锁独立于事件封锁。解除手动封锁不会解除火情，CLEAR才解除当前事件。
区域0/1/2对应一/二/三号出口；3/4/5为西/中/东纵向通道；6/7为北/南横向通道。全部出口不可达时应撤去绿色路线，不继续播报旧出口方向。
