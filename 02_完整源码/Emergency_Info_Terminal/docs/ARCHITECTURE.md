# 系统结构

## 媒体数据通路

TF SPI扇区读取 → FAT32目录及簇链 → BMP/WAV解析 → 图像缩放与SDRAM写入 → 帧缓存 → 扫描及图层合成 → HDMI。
图像与音频共享存储访问，显示读出维持确定节拍。RGB888按四像素三个32位字紧凑存储，四个640×480显示槽共3,686,400字节。

## 控制与时钟

A板参考50 MHz，系统50 MHz、像素25 MHz、串行125 MHz。各域复位同步释放；图像加载命令与完成信息用toggle握手跨域。转场同时保护两幅源图，整帧就绪后才切换显示。
自动播放使用四槽缓存中的三个空闲槽前向预读，2/5/10秒停留从新图完整呈现且转场结束开始。遇未命中时保留旧图并等待，不以连续跳页追赶计时。

## B板协同

控制双向UART为115200 bit/s，独立PCM链路为2.5 Mbit/s。B板从事件管理取得封锁集合，串行Dijkstra求解预设楼层图，输出出口编号、路段掩码和方向。A板验证地图标识、封锁集合及有效期后显示路线。
音频分析为48 kHz、512点Hann窗FFT、256点帧移。频点间隔93.75 Hz；前64频点送显示，全257单边频点用于峰值检测。FFT算子来自安路工具，窗口、缓冲、峰值与串行接口由RTL组织。

## 配置与资源

当前综合配置保留淡入淡出、擦除、滑动、百叶窗四种转场。通用RTL中的可选功能由参数裁剪；源文件存在不代表最终位流启用。所有初始ROM内容均随源代码提供，构建脚本启用eram_init。
