# 第三方模块与设计边界

| 路径 | 来源及用途 | 本项目集成工作 |
|---|---|---|
| vendor/hdmi | 安路HX4S20C配套HDMI发送器及物理接口 | 时钟连接、视频流和音频流接入 |
| vendor/sd | 安路配套SD SPI接口 | FAT32文件访问、图像与音频请求调度 |
| vendor/sdram | 安路配套SDRAM控制器与定义文件 | 紧凑帧存储、仲裁及读回位序适配 |
| console/vendor/fft_512_area.v | 安路TD FFT生成模块 | 512点Hann窗STFT、PCM接入、峰值分析和回传 |

第三方文件保留原始内容、署名、加密封装与工具指令。未对第三方IP作原创声明，授权范围遵循各来源的原条款，未额外授予再许可。
系统级缓存控制、图层合成、字幕进度关联、事件与确认逻辑、双板协议、路线求解及各模块集成为本项目设计内容。
media/TF_A为配套展示素材，包含安全宣传图片及录音。素材仅随作品复现使用；不据此声称拥有第三方素材的独占权。
